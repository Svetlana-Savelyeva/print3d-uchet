# Мастерская 3D — учёт 3D-печати

Веб-приложение для учёта домашней и небольшой бизнес-мастерской 3D-печати: себестоимость каждой печати, склад филамента, брак, продажи и окупаемость принтера.

**Открыть:** https://svetlana-savelyeva.github.io/print3d-uchet/

На телефоне откройте ссылку и выберите «На экран „Домой“» — приложение будет запускаться как обычное и работать без интернета.

## Где хранятся данные

Все записи хранятся **только в браузере** на устройстве (IndexedDB). На сервер и в этот репозиторий ничего не отправляется.

- Телефон и компьютер видят разные данные. Чтобы перенести, используйте «Ещё → Резервная копия → Скачать копию» и «Восстановить из файла».
- Регулярно скачивайте копию: при очистке данных браузера записи пропадут.

## Что умеет

- **Новая печать** за 20–30 секунд: модель, катушки с граммами (изделие, supports, purge, prime tower), время, назначение. Повторная печать подставляет параметры прошлой.
- **Прозрачная себестоимость**: каждая строка «база × ставка = сумма». Прямая = материалы + электричество + прямые расходы. Полная = прямая + амортизация + расходники.
- **Snapshot**: после завершения печати её себестоимость не меняется при изменении цен и настроек.
- **Склад** ведётся журналом движений; цена грамма у каждой катушки своя. Взвешивание сверяет остаток.
- **Брак** — полный или частичный, с причиной; стоимость брака видна отдельно.
- **Назначения**: бизнес (Merino Home), продажа, дом, семья, подарок, тест. Экономия считается, только если указана цена готового аналога.
- **Продажи** с вариантами цены (наценка 50 %, 100 %, рекомендуемая, своя) и учётом комиссии маркетплейса.
- **Окупаемость**: вложено в оборудование и оснащение против экономии и вклада продаж (без повторного вычета амортизации).
- Экспорт в CSV для Excel.

## Для разработчика

Чистый HTML/CSS/JavaScript без сборки и зависимостей.

- `js/calc.js` — все формулы (чистые функции)
- `js/store.js` — хранилище и операции учёта
- `js/views/` — экраны
- `tests/calc.test.mjs` — проверки формул: `node tests/calc.test.mjs`

Локальный запуск: `python3 -m http.server` в папке проекта, затем http://localhost:8000.
